We want it to be a system that provides <b>business value</b>. We need to be able to take this to a company and say "Hey, we know you are already doing A, B, C, but we think your workflow will be improved if you do 1, 2, 3. That can be achieved with our built application." The proposed systems are as follows:
Swimming Pool Management System
Cleaning staff leaves notes based on status
Each client has a dashboard/profile of which they can check the status of their pool
Push Notifications whenever a change occurs on the client pool
Users:
Client
* Requests services like backwash or adding extra chemicals
* Request Cleaning staff
Cleaning Staff


System may Recommend certain actions to be taken based on the current <i>Health</i> of the pool.
